# XR-47

**This may be a dumb name, but the gameplay isn't**

# Bots

There is bot matchmaking. This is just for fun, but still contributes to your K/D.
Bot's auto-fill lobbies if there is lacking players. If there is sufficient players, it should be player-only lobbies

# Queuing

You can queue will normal players from all over the world to fight against.

# Gameplay

You choose your loadout with cool guns and gun sounds.
It's a free-for-all type of game. If you get a set amount of kills, the match ends.
In the settings you can change all kinds of things.

###### It's cooler than it sounds, try it out!
